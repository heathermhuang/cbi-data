# Security

Do not post credentials, private sessions or application data in public issues.
Use the CBI.me private correction channel for a sensitive report. Public queries
accept only bounded structured research identifiers and no applicant identities.

The standalone package has no account/workspace storage, auth implementation,
model calls or arbitrary URL fetching. The monitor is separate and only probes
a merged reviewed HTTPS registry with DNS/stream/request bounds. Report a public
endpoint issue with a minimal synthetic reproduction and preserve factual caveats.
