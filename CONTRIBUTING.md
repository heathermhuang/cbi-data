# Contributing

Propose an exact claim ID/revision, a primary official source URL and locator,
review/effective-date distinctions, original factual wording and a rationale.
Identify legal changes separately from research corrections or new coverage.
Attest that your contribution is original or you have rights to contribute it
under the applicable licence. Do not paste upstream pages or paid tables.

Never submit identities, application files, passport numbers or private histories.
Use CBI.me's private corrections channel for sensitive reports; public issues are
for public programme facts. Maintainers decide evidence meaning and publication
suitability. Automation cannot silently promote a source observation to confirmed.
Unresolved consequential interpretations need specialist review. Run npm run check
and npm run scan; preserve explicit gaps, conflicts, conditions and old revisions.
